# Text playground

A shared vocabulary for an interactive composition in which text flows around a movable shape.

## Language

**Obstacle**:
A circular object that reserves space the text must flow around.
_Avoid_: Image, photo, cursor

**Essay**:
The curated starting text about reading, space, and meaning.
_Avoid_: Placeholder, sample data

**Composition**:
The arrangement of the current text and obstacle within the playground.
_Avoid_: Document, saved project

**Layout view**:
The optional explanatory view that reveals line boundaries and describes how the text fits around the obstacle.
_Avoid_: Debug mode, developer console
